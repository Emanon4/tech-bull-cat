# 官网融合审查与修复 · 2026-10-30

## 结论

原版完成了作品画廊上线，但账号介绍仍是一套独立旧站。仅增加互相跳转的入口，没有形成统一的官网体验。本轮将账号定位、作品与合作入口组织在同一页面，旧版作为历史资料保留。

## 实际访问流程与发现

| 步骤 | 原有问题 | 本轮处理 |
| --- | --- | --- |
| 1. 从首页认识品牌 | 首屏直接进入米哈游作品，对创作者定位缺少说明 | 增加简洁的品牌介绍与账号介绍入口，保留作品主视觉 |
| 2. 进入账号介绍 | 旧站与新站字体、排版不同，旧页出现两层导航 | 把账号介绍融入主站，采用同一导航和视觉系统；旧 URL 按章节兼容跳转 |
| 3. 从介绍判断合作能力 | 内容领域、品牌墙与真实作品脱节 | 合作方向卡片连接对应作品分类；品牌名称连接搜索结果，避免没有案例支撑的品牌墙 |
| 4. 联系商务 | 新旧页面微信不同，访客需要自行判断 | 主站统一使用已核对的 qianpai857；旧联系方式只在明确标示的历史存档中保留 |
| 5. 判断数据和图片性质 | 旧站统计与新作品快照混用；卡片单独观看时缺少数字人标注 | 主站使用同一作品数据与采集日期；每张场景卡片标注数字人演绎 |
| 6. 手机端页内导航 | 实测发现 hash 导航触发列表重绘，造成滚动跳偏 | 仅在查询条件改变时重绘，首次载入后定位目标章节 |

## 仍可迭代

- 将部分代表作扩展成完整案例：实际传播目标、内容切入方式、交付成果；需要真实项目材料，不能从播放量推断商业效果。
- 目前是 9 张数字人场景图与原片索引，尚无数字人视频或对话能力；本轮未将静态图描述为这些功能。
- 全网粉丝与品牌授权关系应有新的核对记录后再更新展示，旧版记录继续保留供查阅。
- 本轮未测试所有外部平台的登录后播放；外链仍由平台自身的登录或地区限制决定。
